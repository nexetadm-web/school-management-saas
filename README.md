# 🏫 School Management SaaS - Multi-Tenant Portal

A Modern, Fast & Secure SaaS Platform for Schools to manage Fees, Students, Teachers, Salary & Expenses.

Built with **Next.js 15, Tailwind CSS & Supabase.**

### 📸 Dashboard Preview

![Dashboard Overview](screenshots/dashboard.png)

> Dashboard Overview - Multi-Tenant Fee Management Portal with Real-time Analytics

### ✨ Key Features

- 🔐 **Multi-Tenant Architecture** - Har school ka data 100% alag aur secure
- 💰 **Smart Fee Management** - Monthly Collection, Pending Fees, Trend Chart
- 👨‍🎓 **Student Management** - Add, Edit, Track Students
- 👨‍🏫 **Teacher & Salary** - Faculty count & Salary tracking
- 💵 **Expenses & Net Profit** - Auto Profit = Income - (Salary + Expenses)
- 📊 **Financial Distribution** - Visual Charts for income vs expense
- 👑 **Super Admin Panel** - Saare schools ko control karo
- ⚡ **Live Recent Activity** - Real-time updates

### 🛠️ Tech Stack

- **Frontend:** Next.js 15 (App Router), TypeScript, Tailwind CSS
- **Backend & DB:** Supabase (PostgreSQL, Auth, RLS)
- **Deployment:** Vercel
